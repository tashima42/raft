## Package: main

- `main.go`: Is the entry point of the application, it parses the command line
arguments and initializes the Raft server, the gRPC server and the HTTP server
for the key-value store.
- `handlers.go`: Holds the HTTP handlers for the key-value store.
- `grpc_e2e_test.go`: Holds the end-to-end tests for the Raft cluster using gRPC clients. Generated by copilot. Might not be reliable.

## Package: raft

- `raft.go`: Holds all the initialization logic and the main goroutine that
checks the server state and the leader goroutine to send hearbeats to followers.
- `rpcs.go`: Holds the functions that leaders and candidates can call via RPCs.
- `elections.go`: Holds functions that checks if the election timeout has
expired and starts an election if it has.
- `stable_storage.go`: Is a wrapper around the database package with minimal
checks and transformations to prevent runtime errors.
- `peer.go`: Holds the Peer struct and its methods
- `keyval.go`: Is a dead simple key-value store based on actions, used as the
placeholder application for the Raft cluster.
- `client.go`: Holds a gRPC, mock and HTTP client to send requests to peers.

## Package: transport

Translates the Raft server to a gRPC server.

## Package: database

Holds the stable storage implementation using SQLite to store configuration,
server state and log entries.
It also holds a mock implementation of the database for testing purposes.
